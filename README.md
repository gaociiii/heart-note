# 心动纸条

适配手机的真心话大冒险主持助手。题库、收藏、玩家及游戏进度存储于当前浏览器，不使用数据库、不跨设备同步。

- `web/`：页面、题库及浏览器端逻辑。
- `server/worker.mjs`：账号密码验证、签名登录会话及受保护的页面资源。
- `scripts/build.mjs`：把页面资源嵌入 Worker，生成 `dist/server/index.js`。
- `tests/`：题库迁移、导入导出及身份验证测试。

构建：`npm run build`。验证：`npm test`。

部署时设置服务端环境变量 `HOST_USERNAME`、`HOST_PASSWORD_SALT`、`HOST_PASSWORD_HASH`、`SESSION_SECRET`。密码使用 PBKDF2-SHA256（100000 次、32 字节输出、16 字节随机盐），会话为 7 天 HttpOnly / Secure / SameSite=Strict Cookie。凭据不存入源码或前端资源。当前为固定主持人账号，不开放注册。

题库支持 JSON 与 UTF-8 CSV 导入导出。CSV 列：题库、题目、题型、氛围强度、参与方式、收藏；JSON 还保留题库图标和编号。全量导出不受页面筛选影响。支持旧版完整 JSON 备份迁移；旧标签映射：轻松→L1、微甜→L2、走心→L3、刺激→L4；双人迁移为多人。

多人纸条点击「随机一位」时，每次仅选一位玩家；手动指定可勾选一位或多位。首页以完整纸条为中心，氛围在抽取按钮下方展开选择，题型及 L1–L4 强度使用下拉控件，强度支持多选。纸条箱保留搜索入口，将题库、题型、强度和参与方式集中在可展开的筛选面板中，导入导出与新建题库集中在题库管理中。主持人预览中的「换一张」直接在当前卡片更新题目，不关闭预览。

主持人页面的整张名片可点击进入个人信息，样式设置通过下方入口进入；个人信息在当前页面切换编辑与保存，点击头像进入选择页面；头像和样式页面支持返回。四套配色和纸条字号/字体/圆角可自定义。10 个从用户提供图片裁切的内置人像由 `web/avatars.js` 提供，不支持上传。个人信息及样式存于当前浏览器，仅完整备份包含这些信息，题库导出不包含个人信息。

发布为自有账号密码登录时，平台入口需允许匿名访问到应用登录页，实际页面与题库资源由 Worker 会话校验保护。

## 安装与离线使用

网页版和主屏幕应用共用同一个 HTTPS 地址。iPhone 可在 Safari 的分享菜单中选择「添加到主屏幕」，并选择「作为网页 App 打开」（如系统显示该选项）。Android 可在 Chrome 菜单中选择安装或添加到主屏幕，菜单文字因浏览器和设备而异。

从准备离线使用的入口联网登录并打开主持页，让资源加载完成。之后断网也可以重新打开主持页、抽题和记录进度，最长沿用当时会话的有效期。首次登录、会话过期后登录和退出账号需要网络。在线退出会移除离线页面缓存。题库和进度仍由当前应用入口保存在设备上。

iPhone 上 Safari 和主屏幕应用的本机存储各自独立。需要迁移既有题库、收藏和进度时，先在 Safari 中导出「完整备份」，再从主屏幕应用导入。
